# WesGym
Deutschsprachige persönliche PWA für Gewicht, Ernährung und Krafttraining.

## GitHub Pages
Alle Inhalte dieses Ordners in das Repository hochladen. Danach: Settings → Pages → Deploy from a branch → main / root.

## iPhone
In Safari öffnen → Teilen → Zum Home-Bildschirm.

Alle Daten werden lokal gespeichert. Backups sind unter Einstellungen möglich.
