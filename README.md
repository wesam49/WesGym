# WesGym 5.0

Komplett neu gestaltete Version mit derselben lokalen Datenbasis (`wesgym_simple_2_0`) für eine möglichst nahtlose Übernahme vorhandener Einträge.

## Neu in 5.0
- Neue Premium-Light-Oberfläche ohne Emoji-Icons.
- Start → Heute → Ziel als zentrale Reiseansicht.
- Getrennter Fortschritt nach Waage und Kalorienmodell.
- Monatskalender mit Kalorien-, Gewichts- und Trainingsstatus.
- Kalorien-Serie und Gym-Serie (Gym-Serie zählt erfolgreiche Wochen).
- Verlauf mit Soll / Kalorienmodell / Waage.
- Analyse mit echtem Gewichtsverlauf, Kalorienmodell und Sollkurve.
- Prognosen für 7 / 14 / 30 / 60 Tage oder ein frei wählbares Datum.
- Wiederkehrende Trainingstermine mit Bearbeitung einzelner oder zukünftiger Termine.
- Backup / Import / Reset.
