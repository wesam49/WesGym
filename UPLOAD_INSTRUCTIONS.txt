WesGym Update 3

Upload these 3 files to the ROOT of your GitHub repository:

- index.html      (replace old file)
- sw.js           (replace old file)
- update-v3.js    (new file)

Keep all other files.

New behavior:
- Enter start date, start weight, maintenance calories and planned calories once.
- WesGym calculates the planned weight for every day automatically.
- You only enter the actual weight.
- Daily comparison: ahead of plan / behind plan / on plan.
- Main evaluation uses the 7-day actual average versus the 7-day planned average.
- Changing calories updates future expected weights from the chosen start point.
